# Python Day 124 - Find Minimum Number

This Python program finds the smallest number in a list using the built-in `min()` function.

## Example

List:
```text
[10, 45, 20, 80, 5, 35]
```

Output:
```text
Smallest number: 5
```

## Concepts Used

- Python lists
- `min()` function
- Variables
- `print()` function

## How It Works

The program stores numbers in a list. The `min()` function finds the smallest value in the list, and the result is displayed using `print()`.

## What I Learned

I learned how to find the smallest number in a list using Python's built-in `min()` function.
